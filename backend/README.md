# Annora -- Backend (FastAPI)

Milestone 1 scope: this backend does **not** handle onboarding yet -- that
goes directly from Flutter to Supabase (see root README for why). All this
exposes right now is a health check, to prove the scaffold works and to give
later milestones (meal planning, price aggregation, NLP) a place to land.

## Setup

```
cd backend
python3 -m venv .venv
source .venv/bin/activate   # on Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp ../.env.example .env      # then fill in real values later, not needed yet
```

## Run

```
uvicorn app.main:app --reload
```

Then check:
- http://127.0.0.1:8000/ -> `{"service": "annora-backend", "environment": "development"}`
- http://127.0.0.1:8000/api/v1/health -> `{"status": "ok"}`
- http://127.0.0.1:8000/docs -> interactive OpenAPI docs (auto-generated by FastAPI)

## Test

```
pytest tests/ -v
```

Both tests (`test_health_check_returns_ok`, `test_root_returns_service_name`)
should pass.
